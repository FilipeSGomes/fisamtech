# FISAM TECH typography

- Oxanium (variable 400–700): display headings.
- IBM Plex Sans (variable 400–700): body text, forms and buttons.
- IBM Plex Mono (400, 500): engineering labels and diagram nodes.

WOFF2 Latin and Latin Extended subsets are self-hosted; browsers do not need a Google Fonts request. Source: Google Fonts CSS API / fonts.gstatic.com. Original SIL Open Font Licenses are included alongside the files. Font binaries are unchanged.

Official specimen pages:

- https://fonts.google.com/specimen/IBM+Plex+Sans
